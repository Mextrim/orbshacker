Часто задаваемые вопросы

Ответы на популярные вопросы о работе Orbshacker

Зачем нужен лаунчер (orbshacker-launcher)?
Лаунчер весит всего 1.8 МБ. Он сам подключается к GitHub Releases, скачивает все необходимые компоненты (включая библиотеки Electron и ffmpeg.dll), распаковывает их в правильную структуру папок и запускает приложение. Это гарантирует, что программа всегда будет запускаться без ошибок недостающих DLL.
Безопасно ли это для аккаунта Discord?
Да! Orbshacker не внедряется в память Discord и не модифицирует системные файлы. Он использует стандартный протокол Discord Game Detection и Discord RPC, точно так же, как обычные игры в Windows и Linux.
Как обновить счётчик значка в Discord?
Discord кэширует профиль локально. После завершения пакета фарма просто перезагрузите Discord нажатием Ctrl + R, чтобы увидеть обновленное количество игр и новые значки!
